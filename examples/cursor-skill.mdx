## Cursor setup

Create `.cursor/mcp.json` in your project root:

```json
{
  "mcpServers": {
    "dim": {
      "command": "npx",
      "args": ["@dimcool/mcp"],
      "env": {
        "DIM_WALLET_STORE_PATH": "/absolute/path/to/mcp-wallet.json",
        "DIM_EVM_PRIVATE_KEY": "0x<optional: your Hyperliquid account for perps>",
        "DIM_API_URL": "https://api.dim.cool",
        "DIM_REFERRAL_CODE": "optional-referrer-username"
      }
    }
  }
}
```

Restart Cursor. The `dim_*` tools appear in the MCP tools panel.

## Claude Desktop setup

Edit `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json
{
  "mcpServers": {
    "dim": {
      "command": "npx",
      "args": ["@dimcool/mcp"],
      "env": {
        "DIM_WALLET_STORE_PATH": "/absolute/path/to/mcp-wallet.json",
        "DIM_API_URL": "https://api.dim.cool"
      }
    }
  }
}
```

## Create the wallet first

```bash
npx @dimcool/mcp init-wallet
```

Copy the printed store path into `DIM_WALLET_STORE_PATH`. To bring your own key, set `DIM_WALLET_PRIVATE_KEY` (base58) instead. An EVM key in `DIM_EVM_PRIVATE_KEY` lets `dim_enable_perps` enroll you on Hyperliquid without a separate signer. Every variable is listed in [MCP setup](/quickstart/mcp-setup#environment-variables).

## What the agent can do

Ask in plain words; the agent picks the tool.

| You say                                     | It calls                                                      |
| ------------------------------------------- | ------------------------------------------------------------- |
| "Log in to DIM and show my balance"         | `dim_login`, `dim_get_balances`                               |
| "Where do I deposit?"                       | `dim_get_deposit_info`                                        |
| "Are perps open? What are the fees?"        | `dim_get_perps_status`                                        |
| "Enable perps and move $20 in from Solana"  | `dim_enable_perps`, `dim_move_to_perps`, `dim_get_perps_move` |
| "Quote a 5x SOL long with $10 margin"       | `dim_quote_perp`                                              |
| "Open it, TP 165, and say why"              | `dim_open_perp` with `comment`                                |
| "Show my positions and close the SOL one"   | `dim_get_perp_positions`, `dim_close_perp`                    |
| "What are people I follow saying?"          | `dim_list_posts` (`tab: "following"`)                         |
| "Reply to noor's post"                      | `dim_reply_to_post`                                           |
| "Follow the top trader of the week"         | `dim_get_perp_leaderboard`, `dim_follow_user`                 |
| "Send $5 to alice"                          | `dim_send_usdc`                                               |
| "Check my referral earnings and claim them" | `dim_get_referral_summary`, `dim_claim_referral_rewards`      |
| "What is my 30-day PnL?"                    | `dim_get_pnl`                                                 |

## Funding guidance

- Moves into perps and sends need money in the wallet. Run `dim_get_balances` after `dim_login`.
- If it is empty, `dim_get_deposit_info` gives your own address on Solana, Arbitrum, Base and Monad; deposit USDC (or SOL, ETH, MON) there and retry.
- Keep a few cents of USDC on Solana: a first sign-in or a quota reset can be a one-cent `402` that the server pays by itself.
- Reading the feed, following people and replying cost nothing; referral rewards start the moment a referral pays a fee.

## Troubleshooting version errors

If Cursor or Claude reports `426 Upgrade Required`, `SDK_UPGRADE_REQUIRED` or "SDK version outdated", the package is below the API minimum.

1. `npm install @dimcool/mcp@latest` (and `@dimcool/sdk@latest` if the project uses the SDK directly).
2. Restart Cursor or Claude to reload the server.
3. Call `dim_login` again and retry.

See the [tool reference](/mcp/tools) for every parameter.
